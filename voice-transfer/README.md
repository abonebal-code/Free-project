<table>

<td width="50%">

### 🎯 النقل التلقائي
- نقل فوري لأي عضو يدخل قناة الانتظار  
- يتوقف تلقائياً عند خروج المُشغِّل من القناة الخاصة  
- معالجة ذكية لأخطاء النقل دون تعطّل النظام  

### 🏠 متعدد السيرفرات
- كل سيرفر له ملف إعدادات منفصل  
- الجلسات معزولة تماماً بين السيرفرات  
- إضافة سيرفر جديد بمجرد إنشاء مجلد  

</td>
<td width="50%">

### 🔥 Hot Reload
- إعادة تحميل إعدادات أي سيرفر تلقائياً عند تعديلها  
- لا حاجة لإعادة تشغيل البوت أبداً  

### 🔒 نظام صلاحيات مرن
- تحكم دقيق عبر IDs المستخدمين أو الرولات  
- fallback تلقائي لصلاحية `Administrator`  

### 📩 رسائل DM مخصصة
- إشعار تلقائي لكل عضو عند دخوله قناة الانتظار  
- متغيرات ديناميكية في نص الرسالة  

### 📋 سجل العمليات
- embed منسق لكل عملية نقل  
- سجل منفصل عند الإيقاف التلقائي

## ⚙️ كيف يعمل

```
1. المُشغِّل يدخل قناته الخاصة الصوتية
2. يكتب: !تشغيل نظام النقل
3. النظام يبدأ مراقبة قناة الانتظار
4. أي عضو يدخل قناة الانتظار → يُنقل فوراً إلى القناة الخاصة
5. المُشغِّل يخرج من القناة → النظام يتوقف تلقائياً
```

## 🚀 طريقة التشغيل

### المتطلبات

| المتطلب | الإصدار |
|---------|---------|
| Node.js | `18.0.0` أو أحدث |
| discord.js | `v14` |

> **ملاحظة:** هذا النظام **وحدة (module)** تُضاف إلى بوت Discord.js موجود، وليس مشروعاً مستقلاً.

### التثبيت

**1. انسخ المجلد داخل مشروع البوت:**
```
your-bot/
├── main.js
├── voice-transfer/   ← ضع المجلد هنا
│   ├── index.js
│   ├── handler.js
│   ├── commands.js
│   └── servers/
└── package.json
```

**2. أضف السطر التالي في ملف `main.js` الخاص بك:**
```js
const client = new Client({ /* ... */ });

// تفعيل نظام النقل الصوتي
require('./voice-transfer')(client);
```

**3. تأكد من وجود صلاحيات البوت اللازمة:**

| الصلاحية | الهدف |
|----------|-------|
| `Move Members` | نقل الأعضاء بين القنوات الصوتية |
| `View Channels` | رؤية قنوات الانتظار |
| `Send Messages` | إرسال ردود الأوامر |
| `Embed Links` | إرسال الـ embeds في السجل |

## 🔧 إعداد السيرفرات

### إضافة سيرفر جديد

**1. أنشئ مجلداً باسم السيرفر داخل `servers/`:**
```
servers/
└── my-server-name/
    └── config.js     ← أنشئ هذا الملف
```

**2. انسخ هذا القالب واملأه:**

```js
module.exports = {

  // ─── معلومات السيرفر ────────────────────────────────────────────
  guildId:    "ضع_ID_السيرفر_هنا",   // ← مطلوب
  serverName: "اسم السيرفر",          // للعرض في السجلات فقط

  // ─── قناة الانتظار الافتراضية ──────────────────────────────────
  // يمكن تجاوزها عند كتابة الأمر: !تشغيل نظام النقل #القناة
  waitingChannelId: "ID_قناة_الانتظار",

  // ─── رسالة الـ DM ───────────────────────────────────────────────
  // المتغيرات: {user} | {serverName} | {channel}
  dmMessage: "مرحباً {user} 👋\nأنت الآن في قائمة الانتظار في **{serverName}**\nسيتم نقلك قريباً 🎙️",

  // ─── صلاحيات الأمر ──────────────────────────────────────────────
  allowedRoles: [
    "ID_الرول_1",
    "ID_الرول_2",
  ],
  allowedUsers: [
    "ID_المستخدم_1",
  ],

  // ─── قناة السجلات ───────────────────────────────────────────────
  logChannelId: "ID_قناة_السجل",   // اتركها "" لتعطيل السجل

  // ─── إعدادات متقدمة ─────────────────────────────────────────────
  sendDM:        true,        // إرسال DM عند النقل
  enableLog:     true,        // تسجيل العمليات
  logEmbedColor: "#5865F2",   // لون الـ embed في السجل
};
```

### جدول خيارات الإعداد

| الخيار | النوع | مطلوب | الوصف |
|--------|-------|--------|-------|
| `guildId` | `string` | ✅ | ID السيرفر على Discord |
| `serverName` | `string` | — | اسم يظهر في السجلات فقط |
| `waitingChannelId` | `string` | — | ID قناة الانتظار الافتراضية |
| `dmMessage` | `string` | — | نص رسالة DM تُرسل للعضو |
| `allowedRoles` | `string[]` | — | الرولات المسموح لها بالأوامر |
| `allowedUsers` | `string[]` | — | المستخدمون المسموح لهم بالأوامر |
| `logChannelId` | `string` | — | قناة إرسال سجل العمليات |
| `sendDM` | `boolean` | — | تفعيل/تعطيل رسائل DM |
| `enableLog` | `boolean` | — | تفعيل/تعطيل سجل العمليات |
| `logEmbedColor` | `string` | — | لون الـ embed (هيكس مثل `#5865F2`) |

### منطق الصلاحيات

```
allowedUsers غير فارغة  →  تحقق من ID المستخدم
allowedRoles غير فارغة  →  تحقق من رولاته
كلاهما فارغ            →  صلاحية Administrator فقط
```

## 💬 الأوامر

### `!تشغيل نظام النقل`
```
!تشغيل نظام النقل
!تشغيل نظام النقل #قناة-الانتظار
!تشغيل النقل
```
يُشغِّل نظام النقل. يجب أن تكون داخل القناة الصوتية الخاصة عند استخدامه.  
- **القناة الخاصة** = القناة الصوتية التي أنت فيها حالياً  
- **قناة الانتظار** = المذكورة في الأمر أو الافتراضية من الإعدادات  

**مثال الرد:**
```
✅ نظام النقل الصوتي — تم التشغيل
📥 قناة الانتظار  │  🔒 القناة الخاصة  │  👤 المُشغِّل
📩 رسالة DM: ✅ مفعّلة
─────────────────────────────────────────────
سيتم إيقاف النظام تلقائياً عند خروجك من القناة الخاصة
```

---

### `!إيقاف نظام النقل`
```
!إيقاف نظام النقل
!إيقاف النقل
```
يوقف الجلسة النشطة يدوياً في السيرفر.

---

### `!حالة النقل`
```
!حالة النقل
!حالة نظام النقل
```
يعرض الحالة الحالية للنظام.

**إذا كان نشطاً:**
```
📊 نظام النقل الصوتي — الحالة
🟢 النظام نشط حالياً.

📥 قناة الانتظار  │  🔒 القناة الخاصة
👤 المُشغِّل       │  ⏱️ مدة التشغيل: 5د 23ث
```

**إذا كان متوقفاً:**
```
📊 نظام النقل الصوتي — الحالة
🔴 النظام غير نشط حالياً.
```

## 📝 أمثلة عملية

### سيناريو جلسة خاصة

```
1. المالك يدخل قناة 🔒 Private Session
2. يكتب: !تشغيل نظام النقل #waiting-room
3. ✅ النظام يبدأ العمل

4. Ali يدخل قناة #waiting-room
   → يتلقى DM: "مرحباً Ali 👋 سيتم نقلك قريباً..."
   → يُنقل فوراً إلى 🔒 Private Session
   → يظهر في #bot-logs: "✈️ تم نقل Ali"

5. المالك يخرج من 🔒 Private Session
   → يظهر في #bot-logs: "🔴 نظام النقل — أُوقف تلقائياً"
```

### hot reload للإعدادات

```
# أثناء عمل البوت، عدّل config.js لأي سيرفر
# سيظهر في الكونسول تلقائياً:
[VoiceTransfer] ⚠️ تغيير رُصد في "my-server/config.js" — إعادة التحميل...
[VoiceTransfer] ✅ تم إعادة تحميل "my-server" — 2 سيرفر نشط
# لا حاجة لإعادة تشغيل البوت
```
